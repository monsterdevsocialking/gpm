GPM — INSTALAÇÃO LOCAL (XAMPP)
================================

1. COLOCAR O PROJETO NA PASTA CORRETA
   Extrai a pasta do projeto para:
   C:\xampp\htdocs\gpm2

   Confirma que estes caminhos existem:
   C:\xampp\htdocs\gpm2\index.php
   C:\xampp\htdocs\gpm2\app\bootstrap.php
   C:\xampp\htdocs\gpm2\cliente\index.php
   C:\xampp\htdocs\gpm2\admin\login.php

2. INICIAR O XAMPP
   Abre o XAMPP Control Panel e inicia Apache e MySQL.

3. CRIAR A BASE DE DADOS
   Abre http://localhost/phpmyadmin
   Cria uma base de dados chamada gpm_mvp_nova.
   Seleciona a base e importa o ficheiro:
   C:\xampp\htdocs\gpm2\gpm_mvp_nova.sql

   Se já tens dados reais nesta base, faz primeiro uma cópia de segurança.
   Não importes o ficheiro completo por cima de uma base com dados existentes.

4. APLICAR A TABELA DE MENSAGENS DE CONTACTO
   Depois de importar o esquema, seleciona gpm_mvp_nova no phpMyAdmin,
   abre o separador SQL e executa o conteúdo de:
   C:\xampp\htdocs\gpm2\database\patch_contact_messages.sql

   O patch cria apenas a tabela contact_messages caso ainda não exista.
   Não apaga nem recria as outras tabelas.

5. CONFIGURAR A LIGAÇÃO
   Abre:
   C:\xampp\htdocs\gpm2\config\database.php

   Por defeito, o XAMPP local usa:
   DB_HOST = localhost
   DB_PORT = 3306
   DB_NAME = gpm_mvp_nova
   DB_USER = root
   DB_PASS = (vazio)

   Se a tua instalação MySQL tiver outra palavra-passe ou nome de base,
   ajusta as variáveis de ambiente ou os valores de configuração.

6. CRIAR O ADMINISTRADOR
   Se ainda não existir uma conta administrativa, abre CMD e executa:

   cd C:\xampp\htdocs\gpm2
   C:\xampp\php\php.exe database\create_admin.php

   Introduz nome, email e palavra-passe com pelo menos 12 caracteres.
   O script não substitui utilizadores existentes.

7. ABRIR O SISTEMA
   Página institucional:
   http://localhost/gpm2/

   Marketplace:
   http://localhost/gpm2/cliente/

   Painel administrativo:
   http://localhost/gpm2/admin/login.php

8. ÁREAS PRINCIPAIS
   - Página institucional: index.php
   - Marketplace: cliente/
   - Conta do cliente: cliente/painel-cliente/
   - Painel administrativo: admin/
   - Funções comuns: app/bootstrap.php
   - Ligação à base de dados: config/database.php

NOTAS IMPORTANTES
-----------------
- A versão principal do marketplace é gpm2/cliente/.
- A pasta gpm2/gpm/ é um pacote anterior/alternativo. Não copies o seu conteúdo
  por cima da versão principal sem comparar os ficheiros.
- O checkout cria o pedido, os artigos, a proforma e a conversa, mas não baixa stock.
  O stock é baixado quando a equipa confirma o pedido no painel.
- Se um pedido confirmado for cancelado, o sistema repõe o stock automaticamente.
- A proforma é uma visualização HTML imprimível e não substitui uma fatura fiscal.
- Antes de publicar em produção, configura HTTPS, credenciais seguras, backups
  e testa todos os fluxos com uma cópia da base de dados.
